日记、随感、长文。研墨落笔，收墨藏稿。

线上：<https://kinghihido.github.io/wuliloutai-writing/>

## 稿件存在哪

**存在本仓库的 `writings/index.json` 里**（整本文集就这一个 JSON 文件，每篇稿子是数组里的一个对象）。

这是 2026-10-31 从「浏览器 localStorage」迁过来的：原来稿子只存在你自己的浏览器里，换设备/清缓存就丢，也没法纯改文件维护。现在改成文件式，**你直接在仓库里改 `writings/index.json` 推上去就更新**，彻底甩开对 AI Agent 的依赖。

两种更新方式：

1. **纯手动（推荐，零 AI）**：用编辑器改 `writings/index.json`，加一个对象，提交推送。字段见下。
2. **用站内的「研墨」写作**：写完点「收墨」，页面会下载一份最新的 `writings/index.json`，你把它覆盖回仓库并提交即可。

每篇稿子的结构：

```json
{
  "id": "1730000000000",
  "title": "题名，留空则取正文首句",
  "kind": "日记 | 随感 | 长文",
  "body": "正文……",
  "ts": 1730000000000,
  "created": 1730000000000
}
```

`id` 用时间戳字符串，`ts` 是最近一次收墨时间、`created` 是首次写成时间（续写时保留）。数组按 `ts` 从新到旧排序展示。

> 还没做一次性迁移的旧稿：打开本页点「导入浏览器旧稿」按钮，会把你浏览器里残留的旧 `jdc.writings` 并入库并下载文件，提交即可。这一步只能你本机做——只有你的浏览器读得到那些旧稿。

## 结构

没有构建步骤、没有后端。结构：

```
index.html          全部页面结构、样式、交互（含 WebGL2 墨染过渡页）
writings/index.json 文集真源：每篇稿子一个对象，数组形式
```

打开方式：起个静态服务（`file://` 直接打开会被浏览器拦 fetch）：

```bash
python -m http.server 8000
```

## 页面里有什么

- **入站过渡页** — WebGL2 流体墨染水面，点一下墨落生漪，再点「入楼台」渐显进正文
- **研墨** — 写作区。题目留空自动取正文首句，体裁分日记 / 随感 / 长文，实时字数
- **藏稿** — 列表。点题名展卷细读，可调出续写；盖印后显示收墨时辰
- **时辰 / 诗签** — 右上角传统时辰，页首随机一句古诗
- **落花** — 右下角开关，飘落花瓣

## 视觉

字体是 Ma Shan Zheng + Noto Serif SC。
